Kestrel Outfitters: one orchestrator, a few simulated workers, one human.
The operator has installed the hook gate (block) and the refund limits.

Act 1 - Dispatch is a card
--------------------------
  orchestrator$ moon card new task --project storefront --title "Fix the CSV order export" --goal "orders export with currency" --done-when "the export tests pass; paste the test summary" --read-first export.py --do-not-touch ../billing/
    #1 filed: task | storefront | Fix the CSV order export
  orchestrator$ moon card new task --project storefront --title "Add a size filter to search" --done-when "the size filter works and its tests pass" --goal "shoppers filter by size" --probe '{"kind": "file", "path": "search.py", "matches": "def filter_by_size"}'
    #2 filed: task | storefront | Add a size filter to search
  orchestrator$ moon card new task --project billing --title "Rate-limit the refund endpoint" --goal "at most 5 refunds per order per hour" --done-when "rate_limit.py caps refunds at 5 per order per hour" --do-not-touch payouts.py
    #3 filed: task | billing | Rate-limit the refund endpoint
  orchestrator$ moon card new task --project storefront --title "Tidy the returns page" --done-when "it reads well"
    #4 filed: task | storefront | Tidy the returns page
  orchestrator$ moon open 4
    refused: #4 has no contract yet (missing goal)
      instead: the orchestrator files it again with the same title plus the missing fields; that updates the card
    (exit 5)
  orchestrator$ moon card new task --project storefront --title "Tidy the returns page" --done-when "it reads well" --goal "returns explained in one screen"
    #4 updated (goal): same card
  => no card, no session (exit 5, INC-001); the refusal says how to get one

Act 3 - A sloppy worker
-----------------------

  orchestrator$ moon close s2-1 --note "handed back without the work"

Act 5 - Kill switch
-------------------
  program$ moon breaker ask refunds refund --amount 49 --host https://api.pay.example/v1 --key order-1042
    refused: breaker: the switch for refunds is off; `moon breaker on --program refunds` asks the human to switch it on
      instead: nothing was paid; `moon breaker status`
    (exit 1)
  worker:s3-1$ moon breaker on --program refunds
    #7 asks the human to switch refunds on (web board, human-only)
  the human, on the board: #7 'switch on' -> HTTP 200, #7: switch on
  program$ moon breaker ask refunds refund --amount 49 --host https://api.pay.example/v1 --key order-1042
    allowed: ticket 26
  program$ moon breaker ask refunds refund --amount 49 --host https://api.pay.example/v1 --key order-1042
    refused: breaker: key 'order-1042' was already allowed once: not twice
      instead: nothing was paid; `moon breaker status`
    (exit 1)
  => off until the human says on; one key pays once (DEC-012); unsure means no (DEC-017)

  a local script, no key: #8 'parcelfast' -> HTTP 401, refused: no board key: this door is the human's

  worker:s3-1$ moon serve
